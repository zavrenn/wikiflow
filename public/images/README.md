# Visual assets

- `wikipedia-globe.png`: AI-generated dimensional puzzle-globe illustration, created for this demo from the selected visual reference. It is illustrative artwork, not the official Wikipedia logo asset. Wikipedia article titles and edit summaries in the interface come from the real feed.
- `openai-blossom.svg`: unmodified official black blossom from the [OpenAI brand assets](https://openai.com/brand/) (`OpenAI-Logos-2025.zip`). OpenAI retains its trademark rights.

Article cards, category labels, measured latency, route selection, and packets are live interface elements. They are not part of the generated image.
